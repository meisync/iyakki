target/buildroot-mac/build/nvidia-open-595.99.02/COPYING): the files are MIT licensed (NVIDIA CORPORATION & AFFILIATES) except where a file
says otherwise, and the Linux kernel interface files are dual MIT / GPL-2.0, as the package recipe states (NVIDIA_OPEN_LICENSE = MIT or GPL-2.0).
The module sources are the ones in this build's dl/nvidia-open/ archive, which legal-extras.sh copies to legal-info/sources/.
Why this folder and not the package: the Mac build's current .config does not select nvidia-open, so `make legal-info` lists no row for it, but
its four .ko files are in the Mac image (they were built earlier and Buildroot keeps files of a deselected package). legal-extras.sh adds the
row from manifest-row.csv only when the tree's build/packages-file-list.txt shows that the package left files behind. The package folder is untouched.
