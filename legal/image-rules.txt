# Review file for the image content scan (`iyakki-relcheck image-scan` / `licence-check`). Paths are matched in lower case, without a leading
# slash; `*` matches any run of characters including `/`.
#   own       | glob | reason            IYAKKI's own files (Apache-2.0), owned by no Buildroot package
#   generated | glob | reason            produced at build time from licensed inputs (indexes, caches, links, copied licence texts)
#   deny      | glob | reason            must never be in an image (vendor blobs, patent-encumbered codecs, restricted fonts); `font:` in front
#                                         limits the pattern to font files
#   except    | glob | reason | date     a reviewed exception to a deny row
#   accept    | package | reason | date  a package whose licence is not provable from legal-info or its recipe but was reviewed
#   require   | path | reason            a root file system must contain this file (licence and notice texts travel with the image)
# Every row needs a reason of a sentence; except / accept also a date.
