# Task T2: Files and Assistant in one app, with an approval card

Make the app with `iyakki new-app bench-t2 --dir <folder outside the repository> --sdk <repository>/crates/iyakki-ui-sdk` (crate `iyakki-app-bench-t2`, type `BenchT2App`, id `bench-t2`). Use the skill `iyakki-app-development`. Finish when `./run.sh app-check <app folder>` prints no problems and the visible test passes.

## What the app does

1. Two tabs named exactly **Files** and **Assistant**. Files is shown first.
2. **Files**: the embedded file browser (FilesView) over the port you are given. When the person opens a text file in it, the app remembers its path and text.
3. A status line at the bottom of both panes: `Opened: <path>` while a file is open, otherwise `No file open`.
4. **Assistant**: the embedded assistant (ChatView). The assistant is told which file is open: give it the open file as a context item of kind Document named by its path with the file's text (and no item when none is open).
5. Two tools of your app: `read_open_file` (a read, no card; answers with the file's text, or `No file open.`) and `close_file` (a change: the person must allow it on a card; afterwards no file is open, the status line says `No file open` and the assistant's context is cleared). Deny leaves the file open.
6. A refusing files port is shown in words (the file view does this); the app must not crash.
