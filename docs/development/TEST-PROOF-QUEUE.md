# Test proof queue (alpha.7 testing lane, 2026-11-18)

Rows whose Test cannot honestly rise above fakes until a person or the dev console runs the proof on the real thing. Rows the hardware lane proved are moved out (see the results section at the end). After a run: set Manual `passed <date> <machine>`, raise Test, run `python3 dist/features/migrate-impl-test.py`.

Common commands (one device at a time, evidence goes to `~/iyakki-work/hwtest/<date>/`):

* Recipe where one exists: `python3 dist/hwtest/hwcheck.py run <recipe-id> --device <name>` (list: `python3 dist/hwtest/hwcheck.py list`).
* UI scenarios: `dist/devtest/run.sh device-ui --device <name> --scenarios <list> --out DIR`.
* QEMU session checks: `dist/qemu/README.md` (after the release gate is done on the Linux host).
* No recipe: follow `docs/development/HARDWARE-TEST-SHEET.md` and the row Notes. Expected result is always the row Feature text (the clause list), read by a person.
