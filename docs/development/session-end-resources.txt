# Every non-test `pub struct` named *Player, *Reader, *Recorder, *Listener, *Capture or *Speaker (and the plural Players/Recorders) and what a sign-out does to it
# (D-SESSION-END; the ratchet is crates/iyakki-core/tests/session_end_registered.rs; the table with the reasons is docs/development/SESSION-END-AUDIT.md).
# Format: path name status [note]. Status is one of:
#   registered:<hook>  a hook of that name ends it (hooks live in iyakki-agent/src/sessionend_hooks.rs, iyakki-shell/src/soundowner.rs, iyakki-shell/src/shell_wake.rs)
#   drop-stops         it ends when its owner (an app or a session object) is dropped, which sign-out does
#   continue           it continues on purpose (the person set it up to run on its own)
#   not-per-person     a parser, a null object, an infrastructure listener or a test helper: no person's session owns it
#   open               not stopped by sign-out yet: listed in the audit, lane SO2 or later. The count may only fall: see `# open-max`.
