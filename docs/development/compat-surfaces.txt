#   kind  id  file  value  class  note
# kind   spec (an iyakki_schema::Spec; value = its current schema number), const (a const with a VERSION, SCHEMA, MAGIC or ABI word in its name;
#        value = its initialiser) or manual (a number that sits as a literal in code; value = text the file must still contain)
# class  surface: a promise to other releases; the note starts with the charter surface letter (A Rust interface, B C interface, C wire
#        protocols, D data on disk, E packages and manifests, F the system itself, G clients). not-ours: looks like a version but is
#        a third party's number, a mask, a limit or a release name.
# A new versioned thing without a row fails the test; a changed value fails until the row is updated (and the release has a fixture
# folder under tests/compat/); a vanished thing fails until its row is deleted (a removed surface is a compatibility event).
