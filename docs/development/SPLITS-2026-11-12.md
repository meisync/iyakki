## Rules applied

* The original row's Feature and Notes describe only what exists; Impl is set to what the written part is (100 where all described work is written). Test and Manual were not touched, so a row stays `partial` until Test 100 and Manual are satisfied.
* Rows whose proposal needs code (class A: a Settings page, the overflowing pages) were not done here; their Impl is unchanged and the code part is named in their Notes: F-CORE-10 and F-DISP-02.
* New browser rows use the area `BROX` (F-BROX-04 onward) because `F-BROW-` is full at 99 and the matrix demands a two-digit number.
* Where a planned row already existed, no duplicate was made: F-APPSTORE-08 points at F-APPSTORE-13 (paid apps and checkout), F-INST-18 was already split (F-DASH-19), F-ARCH-03 shares the new F-ARCH rows with F-ARCH-02, and the relay of F-CORE-10 is the relay row made from F-CORE-07.
