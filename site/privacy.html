Privacy and security

This site does not track you.

Privacy of this site

  • No analytics, no cookies, no scripts, no web fonts, no embedded content, nothing loaded from another site. Every page is plain HTML with one small stylesheet inside it.
  • The pages are served by GitHub Pages. GitHub, like any web host, sees the requests it serves; its own policies apply to that and this project does not receive that data.
  • Links to the repository, the releases and the documents leave this site and go to GitHub.

Privacy of the software

IYAKKI talks only to the models and services you connect, and secrets live in encrypted vaults. The assistant is told that a secret exists, never its value. Details: SECURITY.md and BOUNDARY.md.

Security

  • Report a vulnerability privately, with GitHub's private vulnerability reporting on the repository (Security, then Report a vulnerability). Please do not open a public issue for a security problem. The policy promises an acknowledgement within 7 days. Read SECURITY.md for what to include.
  • Agents are treated as untrusted: roles, scopes, budgets and approvals; guests run in a WebAssembly sandbox; network access goes through an allow-listed egress proxy.
  • Releases are signed (SHA256SUMS, release.json and their signatures); verify before you write an image.
What the alpha does not promise. No security review by anyone outside the project, no penetration test, no Secure Boot on most real machines, no encryption of the whole data volume (vaults and, where switched on, per-person home folders are encrypted), and formats may change between alphas. The full list is in SECURITY.md.

IYAKKI 0.1.0-alpha.2 is an alpha preview for developers and testers, not for production. Licence: Apache-2.0. This site is static: no script, no cookies, no tracking, nothing loaded from another site.
